How the Reward Model Works What is stable, what varies, and what is intentionally excluded

Stored in JSON

Session count, days, UTC time windows, recurring mission types, reward packages, resource types, and planner controls all come from one data file. Maximum rewards are calculated from that data.

Intentionally update-agnostic

The exact objective might be Base XP one month and Dockyard progress the next. The planner cares about the recurring mission and its reward rather than reproducing every PTS article.

First-time rewards excluded

One-time introductory PTS bonuses are not part of the estimate. A new player may therefore receive a little more than this planner predicts.

Maintenance path

If Wargaming materially changes the schedule or recurring mission types, update the JSON model. The UI and calculator consume that structure without monthly HTML edits for ordinary schedule/reward changes.
